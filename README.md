# Mao Records - Sistema de Controle de CDs

Um sistema simples de gerenciamento de CDs, permitindo **inserir, atualizar, buscar, remover e listar CDs** em estoque, além de gerar relatórios.  
Desenvolvido em **Python** com **MySQL** como banco de dados.

---

##  Funcionalidades

- Inserir novo CD no estoque.
- Alterar informações de CDs existentes.
- Pesquisar CDs pelo título.
- Remover CDs do estoque.
- Listar todos os CDs cadastrados.
- Exibir detalhes de um CD específico.
- Gerar relatório de estoque (quantidade total e valor total).

---

##  Tecnologias

- **Python 3**
- **MySQL**
- **dotenv**
